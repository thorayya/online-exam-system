# Online Examination System

A web-based online examination system developed using **PHP, MySQL, HTML, CSS, JavaScript, and AJAX**.

The system provides an interactive platform for conducting online exams. Exam questions and related data are managed through a MySQL database, while PHP handles the server-side logic and AJAX enables asynchronous communication with the backend without requiring a full page reload.

## Main Features

* Online examination interface
* Dynamic loading and management of exam questions
* MySQL database integration
* PHP-based backend
* AJAX-based asynchronous requests
* Interactive user interface
* Exam result processing

## Technologies

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* AJAX

## Running the Project

The project requires a local PHP and MySQL environment such as **XAMPP** or **WAMP**.

The database and required tables are initialized through the project's PHP setup process.
